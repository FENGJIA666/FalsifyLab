# Hackathon contribution

## Built during OSI Hackathon 2026

Developed on October 21-22, 2026, FalsifyLab brings exact counterexample search and traceable claim revision into one workspace. The project delivers a rational-search workbench, a written-claim Euler workflow, reviewable plans, mathematical checks, preserved evidence history and report replay.

## Delivered achievements

- A workflow from a written numerical claim to an exact counterexample.
- A mathematical check that identifies a counterexample beyond the sampled search.
- Claim revisions connected to their complete evidence history.
- Portable JSON and Markdown reports with source fingerprints and revision history.
- Validation through 42 passing tests, independent arithmetic checks and browser report replay.
- A 95-second demonstration and a one-page project explanation.

## Scientific workflow

The demonstration follows the Euler update for y' = -rate*y. FalsifyLab connects interpretation, exact search, mathematical analysis, revision and replay, helping users follow the reasoning behind each result. Python's standard library provides exact rational arithmetic, and the browser presents the investigation as an interactive workspace.

## Value for users

Scientific-computing learners and developers can inspect assumptions, locate exact counterexamples, compare search and mathematical results, and share a reproducible account of how a claim evolved.
