# Hackathon contribution

## Built during OSI Hackathon 2026

Developed on October 21-22, 2026, FalsifyLab brings exact counterexample search and auditable claim revision into one local workspace. The initial rational-search workbench was followed by controlled-English Euler claim interpretation, user-confirmed plans, separate claim and search domains, preserved parent reviews and deterministic replay.

## Delivered achievements

- An end-to-end workflow from a written numerical claim to an exact counterexample.
- Explicit separation of sampled evidence and full-domain scalar Euler analysis.
- Claim revisions that retain the original review and its evidence.
- Portable JSON and Markdown reports with source fingerprints and complete parent history.
- Recorded validation with 42 passing tests, independent arithmetic checks and browser report replay.
- A 95-second captured demonstration and a one-page project explanation.

## Scientific foundation

The demonstration applies established explicit Euler mathematics to scalar decay. FalsifyLab's contribution is the implemented review workflow connecting interpretation, exact search, analysis, revision and replay. Rational arithmetic uses Python's standard library; the application runs with Python and a browser. Node supports frontend testing, and PDF/video tools produce the presentation materials.

## Value for users

Scientific-computing learners and developers can inspect assumptions, locate exact violations, compare search coverage with analytical results, and share a reproducible record of how a claim evolved.
